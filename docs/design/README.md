# Design records

The design decisions behind Shapeshift, written before each stage was built. They explain *why* things are the way they are; the code and [../ARCHITECTURE.md](../ARCHITECTURE.md) describe *what* exists today. Where a later record differs from an earlier one, the later one wins.

| Record | Topic |
| --- | --- |
| [00-overview.md](00-overview.md) | Goals, architecture, original scope |
| [01-frame-and-image-tools.md](01-frame-and-image-tools.md) | Frame, Crop, Compress, Strip metadata |
| [02-finder-integration.md](02-finder-integration.md) | Finder right-click through macOS Services |
| [03-glass-and-wheel-menus.md](03-glass-and-wheel-menus.md) | Glass design and the first wheel menus |
| [04-pie-wheel-and-settings.md](04-pie-wheel-and-settings.md) | Pie wheel, centre outcome capsule, tabbed Settings |
| [05-glass-and-hit-testing.md](05-glass-and-hit-testing.md) | Combined wheel, hit-testing, Liquid Glass |

Later features (SVG, documents, PDF tools, start at login, selection colour) were small enough not to need a separate record; see [CHANGELOG.md](../../CHANGELOG.md).
