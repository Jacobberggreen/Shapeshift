# Changelog

## 1.0.0

First complete release.

- **Convert** images, audio, video, documents and PDFs locally: Shift-drag a file onto a wheel of target formats, or right-click in Finder.
- **Image tools** (Shift+Option-drag): Frame (rounded card, border, shadow, macOS window frame), Crop, Compress to a target size, Strip metadata.
- **PDF tools**: Pages (reorder, rotate, delete), Split, Merge, Redact (flattens redacted pages so the text is really removed).
- **SVG** in and out, documents (DOCX, DOC, ODT, RTF, HTML, TXT) to PDF, PDF to TXT / PNG / JPG.
- Pie-wheel menu with a live outcome preview (new format and estimated size), plus Two rings, Split ring, Two steps and Classic grid menu styles.
- Liquid Glass look on macOS 26 (frosted material before), selectable selection colour, tabbed Settings, start at login.
- App icon and status bar icon, disk image installer.
